# Source text provenance

The downloadable `1911-JFAAtualizadaLivre.json` maintained by JFAAL is based on Almeida 1911, but the project's original README says the text was revised with AI assistance and that redistribution requires attribution under Creative Commons Attribution 3.0 Brazil. It is not a diplomatic copy of the historic 1911 edition.

Source and required credit, as stated by JFAAL:

- https://github.com/BibliaJFAAL/JFAAL

- License: https://creativecommons.org/licenses/by/3.0/br/

The compact SD data is generated from the JSON by `tools/prepare_bible.py`. Preserve this attribution if sharing the dataset. Firmware source and biblical text are separate works with separate provenance/licenses.
